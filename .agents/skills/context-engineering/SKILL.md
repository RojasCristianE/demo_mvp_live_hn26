# Skill: Context Engineering

## Directivas de Contexto
1. **Densidad de Información:** Provee únicamente la documentación, esquemas y endpoints estrictamente necesarios para la tarea actual.
2. **Eliminación de Ruido:** Evita inyectar librerías no utilizadas o explicaciones redundantes.
3. **Persistencia de Decisiones:** Mantén registradas las decisiones técnicas clave en el `AGENTS.md` para evitar desviaciones durante el desarrollo.
